# Documentation

Choose a section by the job you need the documentation to do. The structure
follows [Diátaxis](https://diataxis.fr/): learning, accomplishing a task, looking up
precise information, and understanding the design are different activities.

## Tutorials — learn through a guided exercise

- [Run your first skill](tutorials/first-skill.md): clarify an outcome and inspect an evidence-bearing result.
- [Rehearse a factory workflow](tutorials/factory-rehearsal.md): validate the examples, inspect readiness, and examine a gate without live side effects.
- [Run a local adapter slice](tutorials/local-slice.md): dispatch one effect-free skill and inspect the validated handoff.
- [Rehearse Quality Factory](tutorials/quality-rehearsal.md): assess an external candidate and consolidate evidence without changes.
